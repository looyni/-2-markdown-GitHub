### Горячие клавиши

Сочетания для практики в Bash с обычным режимом редактирования строки Emacs:

- Перейти в начало команды: <kbd>Ctrl</kbd> + <kbd>A</kbd>.
- Перейти в конец команды: <kbd>Ctrl</kbd> + <kbd>E</kbd>.
- Найти ранее введённую команду: <kbd>Ctrl</kbd> + <kbd>R</kbd>.
- Дополнить имя команды или файла: <kbd>Tab</kbd>.

### Полезный фрагмент кода

Простой скрипт на Bash, который выводит приветствие. Его можно сохранить как `hello.sh` и запустить командой `bash hello.sh`.

```bash
#!/bin/bash

name="Иван"
echo "Привет, меня зовут $name!"
echo "Я изучаю Bash и C#."
```
Переменная `name` хранит имя, а команда `echo` выводит текст в терминал.

> [!WARNING]
> Этот скрипт нужно запускать через Bash, например в Git Bash, а не вставлять как команды PowerShell. Если при запуске появляется ошибка с `\r`, проверь окончания строк файла: для Bash используй LF.
